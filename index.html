Especificación Formal de Gramática y Léxico ▼

Reglas de Producción:

1. PROGRAMA      → INICIO LISTA_DECL FIN
2. LISTA_DECL    → [ INSTRUCCION ]*
3. INSTRUCCION   → TIPO IDENTIFICADOR = EXPRESION ; | 
                   IDENTIFICADOR = EXPRESION ; | 
                   print ( VALOR ) ; | 
                   leer ( IDENTIFICADOR ) ; | 
                   if ( CONDICION ) { LISTA_DECL } | 
                   while ( CONDICION ) { LISTA_DECL }
4. TIPO          → int | boolean | string
5. CONDICION     → EXPRESION OPERADOR EXPRESION
6. EXPRESION     → VALOR | VALOR OPERADOR VALOR
7. VALOR         → NUMERO | CADENA | true | false | IDENTIFICADOR

Componentes Léxicos:

8. IDENTIFICADOR → LETRA [ LETRA | DIGITO ]*
9. NUMERO        → DIGITO [ DIGITO ]*
10. CADENA       → " [ CARACTER ]* "
11. OPERADOR     → @ | # | > | < | == | != | <= | >=
12. LETRA        → a | b | c | ... | z | A | B | C | ... | Z
13. CARACTER     → LETRA | DIGITO | " "
14. DIGITO       → 0 | 1 | ... | 9
15. ASIGNACIÓN   → =
16. DELIMITADOR  → ; | ( | ) | { | }
