[+] Ver Gramática de Referencia 
1. PROGRAMA      → INICIO LISTA_DECL FIN
2. LISTA_DECL    → [ INSTRUCCION ]*
3. INSTRUCCION   → TIPO IDENTIFICADOR = EXPRESION ; | IDENTIFICADOR = EXPRESION ; | print ( VALOR ) ; | leer ( IDENTIFICADOR ) ; | if ( CONDICION ) { LISTA_DECL } | while ( CONDICION ) { LISTA_DECL }
4. TIPO          → int | boolean | string
5. CONDICION     → EXPRESION OPERADOR EXPRESION
6. EXPRESION     → VALOR | VALOR OPERADOR VALOR
7. VALOR         → NUMERO | CADENA | true | false | IDENTIFICADOR
----------
LÉXICO:
ID → LETRA [ LETRA | DIGITO ]*
NUMERO → DIGITO [ DIGITO ]*
CADENA → " [ CARACTER ]* "
OPERADOR → @ | # | > | < | == | != | <= | >=
ASIGNACIÓN → =
DELIMITADOR → ; | ( | ) | { | }
